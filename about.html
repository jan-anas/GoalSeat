About Us

Welcome to GoalSeat (our CPIS-358 assignment). We created this website to help users browse football matches and request tickets in a simple and smooth manner.

Our website allows users to:

  • View available football matches and live scores
  • Check ticket prices and categories
  • Help users buy tickets in the easiest way possible
  • Review match details clearly in one place

Our goal is to provide a simple and clean interface that makes football ticket booking easier and more organized.


Thank you for using GoalSeat!
